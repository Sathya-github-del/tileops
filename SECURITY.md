# Security policy

TileOps holds SSH keys to people's servers, so security reports are very welcome.

- **Please don't open a public issue for vulnerabilities.** Use GitHub's private vulnerability reporting
  ("Security" tab → "Report a vulnerability") on this repository.
- Include the version (About screen / companion `GET /about`), what you found, and how to reproduce it.
- You'll get an answer as soon as possible; fixes are released as a new version with credit if you want it.

In scope: the Android app, the companion, the generated server setup script and helper.
